VERDICT
-------
The stage works via careful temporal gating and tribal landmines, not sealed
ownership. Highest-risk fights: shared settle/index clocks, content visibility
co-ownership, and one bloom luminance budget shared by neon, fog, and screens.
Option 2 removed tubes from that budget — Sidekick/CRT/fog cores did not.

With POV spot at **0**, C07’s “spot flattens canopy” path is **latent**; C12
(IBL / neon / MeshBasic fills) is the **active** key-light conflict. Restoring
spot **118** without the leaf `onBeforeCompile` patches reopens C07 immediately.

Counts: 6× P1 · 8× P2 · 0× P0 ship-break found
(C07 severity temporarily muted while spot intensity is 0)

--------------------------

   Why: Three writers on “can you see this mesh”

   Why: One luminance treaty; Option 2 only moved tubes out

3. isSettled / introComplete / allowNeon / heavy-effects timers
   Why: Temporal races: hop theft, land hitch, fog/neon out of phase

   Why: Wrong stop boot/capture; fifth stop is a rewrite hazard

   Why: While spot is off, silhouettes / wash / soft-contact holes track neon
   + env, not L0 spot policy. Restoring **118** returns the old L0↔L2 fight.
